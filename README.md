# CAH Sentinel

An independent, opt-in Windows desktop pet and notification companion for monitoring CAH task status.

This repository is a separate project. It does not require changing CAH's scheduler, Planner, Workers, or Git-canonical task state.

**Status:** Project initialized. There is no packaged application or release yet.
